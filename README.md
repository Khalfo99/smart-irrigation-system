
# Smart Irrigation System

## Overview

The Smart Irrigation System is an embedded systems project designed to automate irrigation using soil moisture sensing and intelligent control.

The system continuously monitors soil conditions, controls irrigation pumps automatically, and provides remote monitoring capabilities.

> **Project Status:** Concept Design / Under Development

---

## Objectives

- Automate irrigation.
- Reduce water consumption.
- Monitor soil moisture.
- Control water pumps automatically.
- Support remote monitoring.
- Detect system faults.

---

## Features

- Soil moisture sensing
- Automatic pump control
- Manual control mode
- Real-time monitoring
- Fault detection
- Event logging
- Expandable architecture
