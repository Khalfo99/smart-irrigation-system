# Project Requirements

# Smart Irrigation System

## 1. Project Description

The Smart Irrigation System is an embedded system designed to automate irrigation by monitoring soil moisture and controlling water pumps. The system minimizes water consumption while maintaining healthy soil conditions.

---

# 2. Objectives

- Automate irrigation.
- Reduce water waste.
- Improve crop productivity.
- Enable remote monitoring.
- Support future system expansion.

---

# 3. Functional Requirements

The system shall:

- Measure soil moisture continuously.
- Compare moisture readings with predefined thresholds.
- Turn the water pump ON when soil moisture is below the threshold.
- Turn the water pump OFF when the desired moisture level is reached.
- Allow manual pump control.
- Display sensor readings.
- Store irrigation events.
- Notify users in case of system faults.

---

# 4. Non-Functional Requirements

The system should:

- Operate 24/7.
- Consume low power.
- Be reliable.
- Be easy to maintain.
- Be modular and expandable.
- Continue operating even if the Internet connection is unavailable.

---

# 5. Assumptions

- Clean water source is available.
- Stable power supply is available.
- Sensors are properly installed.
- Wi-Fi is available for remote monitoring.

---

# 6. Constraints

- Limited hardware cost.
- Outdoor environmental conditions.
- Sensor accuracy limitations.

---

# 7. Expected Outputs

- Soil moisture readings.
- Pump status.
- Irrigation history.
- Fault alerts.
- System status.
